AI Resume Score

An AI-powered resume analysis platform built with the MERN stack that evaluates resumes, provides a score, and offers personalized feedback to help users improve their chances of getting shortlisted for jobs.

Features :
-- Upload resumes in PDF format
-- AI-powered resume analysis
-- Resume scoring system
-- Detailed feedback and suggestions
-- Skill and keyword evaluation
-- Modern and responsive user interface
-- Secure user authentication
-- Resume history and tracking
